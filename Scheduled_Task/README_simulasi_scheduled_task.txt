Cara menggunakan demo scheduled task:

1. Jelaskan bahwa ini bukan setup automation penuh.
2. Tunjukkan contoh file yang bisa dibaca setiap Jumat.
3. Minta Claude membuat draft weekly summary dari file minggu ini dan minggu sebelumnya.
4. Tekankan bahwa hasil tetap harus direview manusia.
5. Jika ingin membahas scheduled task, jelaskan konsepnya singkat: task berulang dengan format input/output yang jelas.
